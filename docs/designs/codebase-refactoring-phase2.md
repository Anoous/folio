## Vision

### 10x Check
A codebase where no file exceeds 400 lines, every data access goes through a repository,
every error has a typed handler, and the Go worker pipeline uses composable middleware.
The Phase 1 refactoring proved the patterns work; Phase 2 applies them everywhere.
With CC, this is ~2-3 hours of work, not weeks.

### Platonic Ideal
- HomeView: 150-line coordinator declaring *what* appears, not *how*
- Network.swift: 3 files — APIClient (HTTP), DTOs (types), Endpoints (routes)
- ReaderView: layout + menu + insights + content as separate composable views
- Every ViewModel uses unified `Result<T, AppError>` pattern
- ViewState<T> enum for loading/loaded/error/empty across all views
- Go worker: composable pipeline middleware with event-driven architecture
