# Folio iOS 26 Redesign Prototype

This folder contains the latest GPT-Image-2 product prototype direction for Folio iOS.

The design direction is:

- one focused job per screen
- fewer separate cards and repeated icons
- native iOS hierarchy, glass surfaces, hairline separators
- clear states for capture, reading, asking, reviewing, and quota
- evidence and quota shown as trustworthy system information, not marketing

1. `01-workbench.png` - daily workbench
2. `02-capture.png` - capture flow
