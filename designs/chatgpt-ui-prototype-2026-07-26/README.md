## 说明

这是一组视觉原型，不是可运行的 HTML 或 iOS 工程。会话里曾出现多轮被否决的草稿，本目录仅保留最后一轮成稿，并按产品流程重新命名。

这组图表达的主要方向是：暖白底色、深墨绿色主色、编辑感衬线标题，以及以“原文—洞察—证据引用”为核心的阅读与问答体验。它适合作为设计参考，不应覆盖 `docs/product/folio-prd.md` 中的产品范围和阶段定义。

## 使用提示

- 以这些图片作为视觉与交互讨论素材，不把图片中的文案、功能或信息架构视为已确认需求。
- 实现前需重新校准 iOS 原生字体、动态字体、Safe Area、无障碍和深色模式。
- 当前原型覆盖了成功、处理中、降级和证据不足状态，但并未穷尽保存失败、离线、空资料库等状态。
